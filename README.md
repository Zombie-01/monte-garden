# monte-garden

Interactive 3D website for **Monte Garden — Luxury Villas** (Chuluut valley, Bogd Khan Uul, Ulaanbaatar).

- `index.html` — 3D hero (real Bogd Khan terrain), interactive 3D master plan, lifestyle gallery, nature, apartments
- `rooms.html` — 2D apartment floor-plan viewer (14 layouts)
- `scripts/` — asset pipeline (terrain heightmap, master-plan footprints/trees/ground, floor-plan cut-outs, room markers)
- `research/` — collected source material and notes (`research/RESEARCH.md`)

```bash
npm install
npm run dev     # http://localhost:5173
npm run build
```
